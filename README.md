# MiTRAA-Edu – React + JavaScript + Material UI

Modern role-based education portal with **Material UI** and **Framer Motion** animations.

## Stack
- React 19 + JavaScript (JSX)
- Material UI (MUI) v6
- Framer Motion (jaw-drop page & micro animations)
- React Router 7
- Vite 6

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173
